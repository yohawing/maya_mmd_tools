# プロジェクトマネージメントシート (アジャイル開発)

## 1. プロジェクト概要

*   **プロジェクト名:** Maya MMD Tools
*   **目的:** Autodesk Maya に MMD (MikuMikuDance) のモデルおよびモーションファイルをインポートする機能を提供し、MMD コンテンツの Maya での利用を可能にする。
*   **ビジョン:** Maya ユーザーが MMD アセットをシームレスに活用し、より豊かな 3D コンテンツ制作を行えるようにする。

## 2. チーム構成

*   **プロダクトオーナー:** yohawing
*   **スクラムマスター:** yohawing
*   **開発チーム:** yohawing (必要に応じて外部の開発者を招待)

## 3. 開発プロセス

*   **開発手法:** スクラム
*   **スプリント期間:** 1週間 または 2週間 (プロジェクトの状況に応じて調整)
*   **スクラムイベント:**
    *   **スプリント計画:** 各スプリントの開始時に、スプリントバックログを作成。
    *   **デイリースクラム:** 毎日、進捗確認と課題共有。
    *   **スプリントレビュー:** スプリント終了時に、完成したインクリメントを関係者にデモンストレーション。
    *   **スプリントレトロスペクティブ:** スプリント終了時に、プロセス改善のための振り返り。
*   **ツール:**
    *   **タスク管理:** (例: GitHub Issues, Trello, Jira など)
    *   **コード管理:** Git (GitHub)
    *   **コミュニケーション:** (例: Slack, Discord など)

## 4. バックログ管理

*   **プロダクトバックログ:** プロジェクトの全ての要件（機能、改善、バグ修正など）を優先順位付けしてリスト化。
    *   `doc/design.md` の「開発ロードマップ」を基に初期バックログを作成。
*   **スプリントバックログ:** 各スプリントで開発チームがコミットするプロダクトバックログアイテムのサブセット。
*   **ユーザーストーリーの定義:**
    *   `As a [ユーザータイプ], I want to [機能], so that [価値].` の形式で記述。
    *   例: `As a Maya user, I want to import PMX models, so that I can use MMD characters in my Maya scenes.`

## 5. 進捗管理

*   **バーンダウンチャート / バーンアップチャート:** スプリントおよびリリースの進捗を視覚化。
*   **ベロシティ:** チームがスプリントで完了できる作業量の平均値。次スプリントの計画に利用。

## 6. 品質管理

*   **完了の定義 (Definition of Done - DoD):** 各バックログアイテムが「完了」と見なされるための基準。
    *   コードがレビューされた。
    *   ユニットテストがパスした。
    *   統合テストがパスした。
    *   ドキュメントが更新された。
    *   UI テストが完了した。
    *   (その他、プロジェクト固有の基準)
*   **テスト戦略:** `doc/testing.md` を参照。

## 7. コミュニケーション

*   **会議体:** 上記スクラムイベントに加え、必要に応じて技術的な議論のための会議を設定。
*   **情報共有:** コードリポジトリ、タスク管理ツール、コミュニケーションツールを通じて、透明性の高い情報共有を心がける。

## 8. スプリント計画

### 8.1. スプリント 1 (日付: 2025/07/01 - 2025/07/14)

*   **目標:** MMD ファイルパーサーの基礎を確立し、PMD モデルの基本的な読み込みを可能にする。
*   **スプリントバックログ:**
    *   [ ] MMD ファイルフォーマットのバイナリ読み込みクラスの作成 (`mmd_parser.py`)
    *   [ ] PMD ヘッダ情報の解析
    *   [ ] PMD 頂点データの解析
    *   [ ] PMD 面データの解析
    *   [ ] PMD 材質データの解析
    *   [ ] PMD ボーンデータの解析
    *   [ ] `mmd_parser.py` のユニットテストの作成と実行

### 8.2. スプリント 2 (日付: 2025/07/15 - 2025/07/28)

*   **目標:** PMD モデルを Maya シーンにインポートする基本的な機能の実装。
*   **スプリントバックログ:**
    *   [ ] Maya メッシュコンバーターの作成 (`maya_mesh_converter.py`)
    *   [ ] Maya ボーンコンバーターの作成 (`maya_bone_converter.py`)
    *   [ ] PMD モデルのメッシュと材質の Maya へのインポート
    *   [ ] PMD モデルのボーンとスキニングの Maya へのインポート
    *   [ ] 基本的なインポート UI の作成 (`ui.py`)
