# アプリケーション設計ドキュメント

## 1. 概要

本ドキュメントは、Autodesk Maya 用 MikuMikuDance (MMD) ファイルインポートプラグインの設計について記述します。MMD のモデルファイル (.pmd, .pmx) およびモーションファイル (.vmd) を Maya シーンに正確かつ効率的にインポートすることを目的とします。

## 2. MMD ファイルフォーマットの解析

MMD ファイルフォーマットはバイナリ形式であり、PMD、PMX、VMD の3種類が存在します。これらのファイルを正確に解析するためのモジュールを設計します。

### 2.1. PMD (Polygon Model Data)

初期のモデルフォーマット。比較的シンプルで、以下の主要なデータを含みます。

*   **ヘッダ:** バージョン情報、モデル名、コメントなど。
*   **頂点データ:** 座標、法線、UV、ボーンウェイト、ボーンインデックス。
*   **面データ:** 頂点インデックスのリスト。
*   **材質データ:** 色、スペキュラ、アンビエント、テクスチャファイル名など。
*   **ボーンデータ:** ボーン名、親ボーンインデックス、ボーン座標、ボーンタイプ（回転、IKなど）。
*   **IKデータ:** IKボーンのターゲット、チェイン長、反復回数など。
*   **モーフデータ:** モーフ名、モーフタイプ（頂点、UVなど）、モーフターゲットの頂点インデックスとオフセット。
*   **表示枠データ:** UI上のカテゴリ分け。
*   **剛体データ:** 物理演算用の剛体情報。
*   **ジョイントデータ:** 剛体間のジョイント情報。

### 2.2. PMX (Polygon Model eXtended)

PMD の拡張フォーマット。より多くの機能と複雑な構造を持ちます。

*   PMD の全機能に加え、以下の機能が追加・強化されています。
    *   **エンコーディング:** UTF-8/UTF-16 対応。
    *   **追加UV:** 複数セットのUV。
    *   **材質:** スフィアマップ、トゥーン、エッジ、影など、より詳細な設定。
    *   **ボーン:** 複数親ボーン、ローカル軸、変形階層、表示操作など。
    *   **モーフ:** グループモーフ、材質モーフ、ボーンモーフなど、多様なモーフタイプ。
    *   **剛体・ジョイント:** より詳細な設定と種類。
    *   **ソフトボディ:** 布などのシミュレーション。

### 2.3. VMD (Vocaloid Motion Data)

モーションデータフォーマット。以下の主要なデータを含みます。

*   **ヘッダ:** バージョン情報、モデル名など。
*   **ボーンフレーム:** 各ボーンのキーフレームデータ（位置、回転、補間曲線）。
*   **モーフフレーム:** 各モーフのキーフレームデータ（値）。
*   **カメラフレーム:** カメラのキーフレームデータ（位置、回転、視野角、補間曲線）。
*   **照明フレーム:** 照明のキーフレームデータ（色、位置）。
*   **セルフシャドウフレーム:** セルフシャドウのキーフレームデータ。
*   **IK/表示フレーム:** IK の有効/無効、ボーンの表示/非表示。

### 2.4. 解析モジュール (`mmd_parser.py`)

*   各ファイルフォーマットに対応したクラス (`PmdParser`, `PmxParser`, `VmdParser`) を提供。
*   バイナリデータを読み込み、Python のデータ構造（辞書やカスタムクラスのインスタンス）に変換する。
*   エラーハンドリング（ファイルが見つからない、フォーマットエラーなど）を適切に行う。

## 3. Maya へのデータ変換

解析された MMD データを Maya のシーン要素に変換するモジュールを設計します。

### 3.1. メッシュ (`maya_mesh_converter.py`)

*   MMD の頂点データ、面データ、UV、法線を Maya の `mesh` ノードに変換。
*   材質データに基づいて Maya の `lambert`, `blinn`, `phong` などのシェーダーを作成し、テクスチャを適用。
*   頂点カラーが存在する場合は、Maya の `colorSet` に変換。

### 3.2. ボーンとスキニング (`maya_bone_converter.py`)

*   MMD のボーン階層を Maya の `joint` ノードに変換。
*   ボーンの親子関係、ローカル軸を正確に再現。
*   頂点ウェイト情報に基づいて、Maya の `skinCluster` を作成し、メッシュにバインド。
*   IK ボーンが存在する場合は、Maya の `ikHandle` を作成し、適切な設定を行う。

### 3.3. モーフ（ブレンドシェイプ） (`maya_morph_converter.py`)

*   MMD のモーフデータを Maya の `blendShape` ノードに変換。
*   各モーフターゲットを `blendShape` のターゲットとして追加し、適切なウェイトを設定。
*   グループモーフや材質モーフなど、PMX の複雑なモーフタイプへの対応を検討。

### 3.4. 物理演算 (`maya_physics_converter.py`)

*   MMD の剛体データを Maya の `rigidBody` ノードに変換。
*   MMD のジョイントデータを Maya の `constraint` ノード（`pointConstraint`, `orientConstraint`, `parentConstraint` など）に変換。
*   物理演算のシミュレーション設定（質量、摩擦、反発など）を Maya にマッピング。

### 3.5. アニメーション (`maya_animation_converter.py`)

*   VMD のボーンフレームデータを Maya の `joint` ノードの `translate`, `rotate` アトリビュートにキーフレームとして設定。
*   VMD のモーフフレームデータを Maya の `blendShape` ノードのターゲットウェイトにキーフレームとして設定。
*   VMD のカメラフレームデータを Maya の `camera` ノードにキーフレームとして設定。
*   VMD の照明フレームデータを Maya の `light` ノードにキーフレームとして設定。
*   補間曲線を Maya のグラフエディタのカーブに変換。

## 4. プラグインのアーキテクチャ

### 4.1. モジュール構成

```
src/
├── __init__.py
├── plugin_main.py          # Maya プラグインのエントリポイント
├── mmd_importer.py         # メインインポートロジックの呼び出し
├── mmd_parser.py           # MMD ファイルの解析
├── maya_converter.py       # Maya データへの変換（各コンバータのラッパー）
│   ├── maya_mesh_converter.py
│   ├── maya_bone_converter.py
│   ├── maya_morph_converter.py
│   ├── maya_physics_converter.py
│   └── maya_animation_converter.py
└── ui.py                   # ユーザーインターフェース
```

### 4.2. ワークフロー

1.  ユーザーが Maya のメニューから「MMD インポート」を選択。
2.  `ui.py` がファイル選択ダイアログを表示。
3.  ユーザーが MMD モデルファイル (.pmd または .pmx) を選択。
4.  `mmd_importer.py` が選択されたファイルを `mmd_parser.py` に渡し、解析。
5.  解析された MMD データが `maya_converter.py` に渡され、各サブコンバータ (`maya_mesh_converter.py` など) を使用して Maya シーンに変換。
6.  必要に応じて、ユーザーが VMD モーションファイルを選択し、同様にインポート。

### 4.3. ユーザーインターフェース (`ui.py`)

*   ファイル選択ダイアログ。
*   インポートオプション（例: 物理演算をインポートするか、アニメーションをインポートするかなど）。
*   進捗バーやログ表示。

### 4.4. エラーハンドリングとログ

*   ファイル読み込みエラー、フォーマット解析エラー、Maya への変換エラーなどを適切に捕捉し、ユーザーに分かりやすいメッセージで通知。
*   Maya のスクリプトエディタに詳細なログを出力。

## 5. 開発ロードマップ (初期フェーズ)

1.  **PMD モデルのインポート:**
    *   メッシュ、材質、ボーン、スキニングの基本機能。
2.  **PMX モデルのインポート:**
    *   PMD の機能を拡張し、PMX の追加機能（複数UV、詳細な材質、多様なモーフタイプなど）に対応。
3.  **VMD モーションのインポート:**
    *   ボーンアニメーション、モーフアニメーションの適用。
4.  **物理演算のインポート:**
    *   剛体とジョイントの変換。
