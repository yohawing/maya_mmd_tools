# バージョニング戦略

## 概要

Maya MMD Toolsのバージョニング戦略は、段階的なリリースを通じて品質を確保しながら、ユーザーに早期アクセスを提供することを目的としています。

## バージョニング体系

[セマンティックバージョニング](https://semver.org/lang/ja/)を採用し、以下の形式を使用します：

```
MAJOR.MINOR.PATCH-PRERELEASE
```

- **MAJOR**: 後方互換性のない変更
- **MINOR**: 後方互換性のある機能追加
- **PATCH**: 後方互換性のあるバグ修正
- **PRERELEASE**: プレリリース識別子（alpha、beta、rc）

## リリース段階

### アルファ版 (Alpha)
- **バージョン形式**: `0.1.0-alpha.1`, `0.1.0-alpha.2`, etc.
- **目的**: 早期テストとフィードバック収集
- **対象ユーザー**: 開発者、アーリーアダプター
- **特徴**:
  - 基本機能は動作するが、不安定な場合がある
  - APIは頻繁に変更される可能性がある
  - バグが存在する可能性が高い
  - 限定的なドキュメント

### ベータ版 (Beta)
- **バージョン形式**: `0.2.0-beta.1`, `0.2.0-beta.2`, etc.
- **目的**: 機能の安定化とバグ修正
- **対象ユーザー**: パワーユーザー、テスター
- **特徴**:
  - 主要機能は安定している
  - APIの大きな変更は避ける
  - ドキュメントがより充実
  - パフォーマンスの最適化

### リリース候補版 (Release Candidate)
- **バージョン形式**: `0.3.0-rc.1`, `0.3.0-rc.2`, etc.
- **目的**: 最終テストと品質保証
- **対象ユーザー**: 一般ユーザーの一部
- **特徴**:
  - 正式版とほぼ同じ品質
  - 重大なバグのみ修正
  - 完全なドキュメント
  - APIは凍結

### 正式版 (Stable)
- **バージョン形式**: `1.0.0`, `1.1.0`, etc.
- **目的**: 本番環境での使用
- **対象ユーザー**: すべてのユーザー
- **特徴**:
  - 完全にテスト済み
  - 安定したAPI
  - 包括的なドキュメント
  - 長期サポート

## バージョン更新手順

### アルファ版の更新
```bash
# 現在: 0.1.0-alpha.1
# 次回: 0.1.0-alpha.2

# mmd_tools/__init__.py を更新
__version__ = "0.1.0-alpha.2"

# タグを作成
git tag -a v0.1.0-alpha.2 -m "Release version 0.1.0-alpha.2"
```

### ベータ版への移行
```bash
# アルファ版最終: 0.1.0-alpha.5
# ベータ版初回: 0.2.0-beta.1

# mmd_tools/__init__.py を更新
__version__ = "0.2.0-beta.1"
```

## ユーザーへの案内

### アルファ版使用時の注意
1. **バックアップを取る**: 重要なプロジェクトでの使用前に必ずバックアップ
2. **フィードバック歓迎**: バグ報告や機能要望を積極的に受け付け
3. **頻繁な更新**: 週次または隔週でのアップデート予定
4. **破壊的変更**: APIや設定が変更される可能性

### フィードバックチャンネル
- GitHub Issues: バグ報告
- GitHub Discussions: 機能要望、質問
- Discord/Slack: リアルタイムサポート（将来設置予定）

## 長期サポート (LTS) 計画

正式版リリース後：
- **v1.0.x**: 2年間のバグ修正サポート
- **v2.0.x**: v1.0.xのサポート終了後にリリース
- セキュリティ修正は必要に応じて提供

## まとめ

現在の推奨アクション：
1. バージョンを`1.0.0`から`0.1.0-alpha.1`に変更
2. CHANGELOGをアルファ版向けに更新
3. READMEにアルファ版の注意事項を追加
4. GitHubでプレリリースとして公開
