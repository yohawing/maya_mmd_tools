# バージョニング戦略

## 概要

Maya MMD Toolsは、シンプルなセマンティックバージョニングを採用します。

当面は `alpha` / `beta` / `rc` のようなプレリリース識別子を使わず、`0.x` 系を早期リリースとして扱います。未安定であることを示したい場合は、GitHub Release側でPre-releaseに設定します。

## バージョニング体系

形式は以下です。

```text
MAJOR.MINOR.PATCH
```

- **MAJOR**: 後方互換性のない大きな変更。正式安定版は `1.0.0` から始める
- **MINOR**: 機能追加やまとまった改善
- **PATCH**: バグ修正、ドキュメント修正、小さな互換改善

## `0.x` 系の扱い

`0.x` は早期リリースです。API、設定、UI、ファイル構成が変わる可能性があります。

例:

```text
0.1.0  初回公開
0.1.1  小さな修正
0.1.2  追加のバグ修正
0.2.0  まとまった機能追加
1.0.0  安定版
```

## リリース計画

### フェーズ1: 初回公開

**バージョン**: `0.1.0`

**含まれる機能**:
- PMD/PMXファイルインポート
- VMDファイルインポート（ボーン、モーフ、カメラ、照明）
- 基本的なUI（Info、Material、Morph、Boneタブ）
- 多言語対応（日本語/英語）
- Namespace対応

**既知の制限事項**:
- エクスポート機能は未実装
- 物理演算は未完成
- 一部のエッジケースでの不具合

### フェーズ2: 早期改善

**バージョン例**: `0.1.1`, `0.1.2`, `0.2.0`

**追加予定機能**:
- インポート安定性の改善
- より高度なマテリアル設定
- パフォーマンス最適化
- エラーハンドリングの改善

### フェーズ3: 機能拡張

**バージョン例**: `0.3.0` 以降

**追加予定機能**:
- PMD/PMXエクスポート機能
- VMDエクスポート機能
- 物理演算の基本サポート
- バッチ処理機能

### フェーズ4: 正式版

**バージョン**: `1.0.0`

**完成条件**:
- 主要なインポート/エクスポート機能が安定している
- ドキュメントが整備されている
- 代表的なモデルとモーションで手動検証済み
- 既知の重大バグがない

## バージョン更新手順

### パッチ更新

```python
# mmd_tools/__init__.py
__version__ = "0.1.1"
```

```toml
# pyproject.toml
version = "0.1.1"
```

```bash
git tag -a v0.1.1 -m "Release version 0.1.1"
```

### マイナー更新

```python
# mmd_tools/__init__.py
__version__ = "0.2.0"
```

```toml
# pyproject.toml
version = "0.2.0"
```

```bash
git tag -a v0.2.0 -m "Release version 0.2.0"
```

## リリースノート例

```markdown
# Maya MMD Tools v0.1.0

## 新機能
- PMD/PMXファイルのインポート
- VMDアニメーションのインポート（ボーン、モーフ、カメラ、照明）

- エクスポート機能は未実装

## 注意事項
これは早期の0.xリリースです。本番環境での使用は推奨しません。
バグ報告はGitHub Issuesまでお願いします。
```

## ユーザーへの案内

1. **バックアップを取る**: 重要なプロジェクトでの使用前に必ずバックアップ
2. **フィードバック歓迎**: バグ報告や機能要望を積極的に受け付け
3. **破壊的変更の可能性**: `1.0.0` まではAPIや設定が変更される可能性がある

## フィードバックチャンネル

- GitHub Issues: バグ報告
- GitHub Discussions: 機能要望、質問
