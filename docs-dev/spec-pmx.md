# PMX仕様 サマリー (v2.1対応)

## 概要

PMXは、MikuMikuDance（MMD）で使用される3Dモデルフォーマットです。PMDの後継として開発され、より高度な機能を提供します。

### 基本情報
- **形式**: バイナリのみ
- **バイト順**: リトルエンディアン
- **テキストエンコード**: UTF-16LE または UTF-8
- **現在の最新バージョン**: 2.1
- **互換性**: バージョンで厳密に管理

## 基本データ型

| 型名 | サイズ | 説明 |
|------|--------|------|
| byte | 1 | 符号なし |
| sbyte | 1 | 符号あり |
| ushort | 2 | 符号なし |
| short | 2 | 符号あり |
| uint | 4 | 符号なし |
| int | 4 | 符号あり |
| float | 4 | 単精度実数 |
| float2 | 8 | Vector2 (X,Y) |
| float3 | 12 | Vector3 (X,Y,Z) |
| float4 | 16 | Vector4 (X,Y,Z,W) |
| TextBuf | 可変 | 4 + バッファ長 |
| bitFlag | 1 | 8フラグ (bit 0:OFF 1:ON) |

### Index参照のサイズ最適化
各データのIndex参照値はデータ総数に応じて1,2,4バイトで最適化されます。
- **頂点**: 符号なし (1:0～255, 2:256～65535, 4:65536～2147483647)
- **その他**: 符号あり (1:0～127, 2:128～32767, 4:32768～2147483647)

## PMXヘッダ

```
4 bytes: "PMX " (ASCII 0x50,0x4d,0x58,0x20)
4 bytes: float version (2.0/2.1)
1 byte:  後続データ列のバイトサイズ (8固定)
8 bytes: 設定情報
  [0] エンコード方式 (0:UTF16, 1:UTF8)
  [1] 追加UV数 (0～4)
  [2] 頂点Indexサイズ (1,2,4)
  [3] テクスチャIndexサイズ (1,2,4)
  [4] 材質Indexサイズ (1,2,4)
  [5] ボーンIndexサイズ (1,2,4)
  [6] モーフIndexサイズ (1,2,4)
  [7] 剛体Indexサイズ (1,2,4)
```

TextBuf: コメント英
```

## 頂点データ

### 基本構造
```
float3: 位置 (x,y,z)
float3: 法線 (x,y,z)
float2: UV (u,v)
float4[n]: 追加UV (x,y,z,w) × 追加UV数
byte: ウェイト変形方式
```

### ウェイト変形方式
- **BDEF1 (0)**: 単一ボーン
- **BDEF2 (1)**: 2ボーン + ウェイト値
- **BDEF4 (2)**: 4ボーン + 各ウェイト値
- **SDEF (3)**: BDEF2 + SDEF用パラメータ
- **QDEF (4)**: デュアルクォータニオン方式 (v2.1)

```
float: エッジ倍率
```

## 面データ

```
頂点Index × 3 (三角形面)
```
- 材質毎の面数は材質内で管理
- v2.1ではPoint描画(A-A-A)、Line描画(A-B-A)もサポート

## テクスチャ

```
TextBuf: テクスチャパス
```
- 材質から参照されるテーブル
- 共有Toon (toon01.bmp～toon10.bmp) は含まれない

## 材質データ

```
TextBuf: 材質名
TextBuf: 材質名英
float4: Diffuse (R,G,B,A)
float3: Specular (R,G,B)
float: Specular係数
float3: Ambient (R,G,B)
bitFlag: 描画フラグ
  0x01:両面描画, 0x02:地面影, 0x04:セルフシャドウマップ描画
  0x08:セルフシャドウ描画, 0x10:エッジ描画
  0x20:頂点カラー(v2.1), 0x40:Point描画(v2.1), 0x80:Line描画(v2.1)
float4: エッジ色 (R,G,B,A)
float: エッジサイズ (Point描画時はPointサイズ)
テクスチャIndex: 通常テクスチャ
テクスチャIndex: スフィアテクスチャ
byte: スフィアモード (0:無効, 1:乗算sph, 2:加算spa, 3:サブテクスチャ)

ToonテクスチャIndex または 共有Toon番号
TextBuf: メモ

```

## ボーンデータ

```
TextBuf: ボーン名
TextBuf: ボーン名英
float3: 位置
ボーンIndex: 親ボーン
int: 変形階層
ushort: ボーンフラグ
```

### ボーンフラグ
- **0x0001**: 接続先表示方法 (0:座標オフセット, 1:ボーン指定)
- **0x0002**: 回転可能
- **0x0004**: 移動可能
- **0x0008**: 表示
- **0x0010**: 操作可
- **0x0020**: IK
- **0x0080**: ローカル付与 | 付与対象 0:ユーザー変形値／IKリンク／多重付与 1:親のローカル変形量
- **0x0100**: 回転付与
- **0x0200**: 移動付与
- **0x0400**: 軸固定
- **0x0800**: ローカル軸
- **0x1000**: 物理後変形
- **0x2000**: 外部親変形

### フラグ依存データ
各フラグに応じて追加データが格納されます：

接続先表示方法が**0**の場合:
```
float3: 座標オフセット, ボーン位置からの相対分
```

IKが**1**の場合:
```
int: ボーンIndexサイズ  | 接続先ボーンのボーンIndex
```

回転可能または移動可能の場合:
```
int  : ボーンIndexサイズ  | 付与親ボーンのボーンIndex
float  : float	| 付与率
```

軸固定が**1**の場合:
```
float3: 回転軸 (X,Y,Z)
```

ローカル軸が**1**の場合:
```
float3: X軸の方向ベクトル
float3: Z軸の方向ベクトル ※フレーム軸算出方法は後述
```

外部親変形が1の場合
```
int: Key値
```

IKが**1**の場合、IKデータを格納します。

```
int: ボーンIndexサイズ  | IKボーンのボーンIndex
ushort: IKループ回数 (PMX及びMMD環境では255回が最大になるようです)
float: IKループ計算時の1回あたりの制限角度 -> ラジアン角 | PMDのIK値とは4倍異なるので注意
int: IKリンク数 : 後続の要素数

IKリンクデータ × IKリンク数
  int: ボーンIndexサイズ  | リンクボーンのボーンIndex
  byte: 角度制限 0:OFF 1:ON
  ----
  角度制限:1の場合
    float3: 下限 (x,y,z) -> ラジアン角
    float3: 上限 (x,y,z) -> ラジアン角

```

## モーフデータ

```

### モーフ種類
- **0**: グループ
- **1**: 頂点
- **2**: ボーン
- **3**: UV
- **4-7**: 追加UV1-4
- **8**: 材質
- **9**: フリップ (v2.1)
- **10**: インパルス (v2.1)

### 主要モーフオフセット
- **頂点モーフ**: 頂点Index + 座標オフセット
- **ボーンモーフ**: ボーンIndex + 移動量 + 回転量(クォータニオン)
- **材質モーフ**: 材質Index + 演算形式 + 各種パラメータ
- **グループモーフ**: モーフIndex + モーフ率

## 変形順序とアルゴリズム

### ボーン変形順序
ボーンの変形順序は以下の3つの項目で正規化後、順に変形を行います：

1. **物理前/後**
2. **変形階層順**
3. **Index順**

#### 変形順序の例
```
A: 前,階層2,Index0
B: 後,階層1,Index1
C: 前,階層0,Index2
D: 後,階層0,Index3
E: 前,階層0,Index4
F: 前,階層1,Index5

↓ 正規化後の変形順序

C: 前,階層0,Index2
E: 前,階層0,Index4
F: 前,階層1,Index5
A: 前,階層2,Index0

<物理演算>

D: 後,階層0,Index3
B: 後,階層1,Index1
```

### 変形パラメータ
1つのボーンが所持する変形パラメータ：

```
・ユーザー操作による回転/移動量
・ボーンモーフによる回転/移動量
・付与ありの場合：付与回転/付与移動量
・IKリンクの場合：IK回転量
・ボーン変形処理によるローカル変形状態
・頂点など形状変形用のグローバル変形状態
```

### 付与システム
付与は付与親ボーンの変形量を自分自身の変形量に加える変形を行います。

#### 付与対象変形量
- ユーザー操作による回転/移動量
- ボーンモーフによる回転/移動量
- 付与ありの場合：付与回転/付与移動量
- IKリンクの場合：IK回転量

#### 付与の種類
- **ローカル付与**: 付与親のローカル変形量を参照
- **グローバル付与**: 付与親のユーザー操作量等を参照
- **多重付与**: 付与変形量を保存し、別の付与ボーンから参照可能

### 変形パラメータの適用順序
```
0. すべてのボーンのローカル/グローバル変形状態を初期化
1. ユーザー操作の回転/移動量をすべてのボーンに設定
2. ボーンモーフによる回転/移動量を対応するボーンに設定
3. 変形順序の正規化
4. 正規化後の順にボーン変形を行う
   4.1. ボーンのローカル変形
   4.2. IKの場合IK変形
```

### ローカル変形順序

#### 回転量（クォータニオン）の計算
**ローカル付与ではない場合**:
```
[親付与回転量(or 親回転 * 親回転モーフ) * 付与親のIKリンク]:付与率 * 回転 * 回転モーフ * IKリンク
```

**ローカル付与の場合**:
```
[付与親のローカル変形量(行列)の回転成分]:付与率 * 回転 * 回転モーフ * IKリンク
```

#### 移動量（3Dベクトル）の計算
**ローカル付与ではない場合**:
```
[親付与移動量(or 親移動 + 親移動モーフ)]*付与率 + 移動 + 移動モーフ
```

**ローカル付与の場合**:
```
[付与親のローカル移動量]*付与率 + 移動 + 移動モーフ
```

### 特殊機能

#### 制限軸
PMDの捩りボーンと同系の仕組み。操作時の移動及び回転軸を指定した軸方向で固定化する機能。

#### ローカル軸
操作上のローカルフレームを任意に定義するための軸方向パラメータ。X/Zで指定し、直交関係ではない場合は以下で補正：
```
Y = Vector3.Cross(Z, X);
Z' = Vector3.Cross(X, Y);
```

#### 外部親変形
指定されたボーンはモデル外部のボーンを親ボーンとして変形することが可能。識別用ID（Key値）を使用。

## 実装時の注意点

1. **バージョン管理**: 非対応バージョンは処理中断
2. **エンディアン**: リトルエンディアン必須
3. **Index最適化**: データ数に応じたサイズ調整
4. **変形順序**: 正確な順序での変形処理
5. **多重付与**: 付与親の依存関係に注意
6. **物理演算**: Bullet 2.75基準での実装
7. **テクスチャパス**: 相対パス対応
8. **エラーハンドリング**: 不正データでの安全な処理中断
