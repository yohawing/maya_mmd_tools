# 腕をIKで操作する

コントロールリグ管理の「腕 IK / FK」から、手首の位置・向きと肘の方向を操作できます。左右の腕を個別に切り替えます。PMXの骨を追加・削除する機能ではありません。

## 操作手順

1. アニメーターツールセットから「コントロールリグを管理」を開き、対象キャラクターを選びます。
2. 「セットアップ」、または「コントロールリグへベイク」で編集状態にします。
3. 左腕または右腕の「IK」を押します。現在のFK姿勢に合わせて切り替わり、手首コントローラが選択されます。
4. 手首を移動・回転します。肘の向きを変えるときは「肘を選択」を押し、肘方向のコントローラを移動します。通常のMaya操作でキーを設定できます。

手首と肘方向のコントローラはワールド空間に置かれます。胴体やモデルのルートを動かすと肩が追従し、手首は指定した位置を保とうとします。腕の長さを超える位置には届きません。

## FKへの切り替えと復元

| ボタン | 結果 |
| --- | --- |
| IK | 現在のFK姿勢に合わせてIKへ切り替えます。すでにIKの場合は手首を選択します。 |
| FK | 現在のIK姿勢を現在フレームのFKキーにして切り替えます。 |
| 元のFKへ | 直前にIKを有効にした時点のFK接続とキーへ戻します。現在のIK姿勢は残しません。 |

再びIKへ切り替える場合も、既存の手首・肘方向のキーを削除する必要はありません。現在フレームの姿勢合わせを行い、他フレームのキーは保持します。この切り替え自体はアニメーション可能なIK/FKブレンド属性ではありません。

## 編集結果をMMDへ戻す

「MMDリグへベイク」で、IKの評価結果をMMD骨のキーへ戻します。既存のFKキーと手首・肘方向のキーを含む範囲を評価します。その後、通常のVMD出力を使用できます。

スクリプトからベイク範囲を指定する場合、腕IKが有効で、元のFKまたはMMD曲線に範囲外のキーがあると停止します。キーを失わないよう、全キーを含む範囲を指定してください。管理画面からのベイクでは範囲を自動で求めます。

「MMDリグの復元」や「コントロールリグの削除」は編集前のMMD接続へ戻す操作です。編集したIKの結果を残す場合は、先にベイクしてください。

手首ターゲットと捩り骨を同時に動かす一部のモーションは、VMD出力の精度検査で停止します。1フレームの途中で回転軸が変化すると、VMDの回転補間では許容誤差内に収まらない場合があるためです。整数フレームの姿勢が一致していても、フレーム間まで一致するとは限りません。エラーで示された骨と区間の動きを調整してから、再度出力してください。

## 現在の対応範囲

通常の腕・肘・手首の3役を持つコントロールリグが対象です。付与、ボーンモーフ、レイヤーなどの特殊な入力経路を持つ腕や、変形階層に1以外のスケールがある構成は、理由を表示して停止します。既存のPMX腕IKを自動変換する機能ではありません。

「arm IK currently requires direct bone input routes」と表示された場合、腕・肘・手首のいずれかが特殊な入力経路を使っています。既存の腕IKを追加したPMXでは、腕や肘の付与がこの制限に該当することがあります。モデルに腕IKを追加していない通常版があれば、その通常版を読み込み、コントロールリグをセットアップしてから腕IKを有効にしてください。腕IK追加版の骨を手動で削除する必要はありません。

保存された所有情報や接続が手動で変更された場合も、他の入力を切断して操作を続けることはありません。通常の切り替えは管理画面から行ってください。
