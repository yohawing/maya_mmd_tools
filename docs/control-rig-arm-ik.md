# 腕をIKで操作する

コントロールリグ管理の「腕 IK / FK」から、手首の位置・向きと、上腕回転による肘の方向を操作できます。左右の腕を個別に切り替えます。PMXの骨を追加・削除する機能ではありません。

## 操作手順

1. アニメーターツールセットから「コントロールリグを管理」を開き、対象キャラクターを選びます。
2. 「セットアップ」、または「コントロールリグへベイク」で編集状態にします。
3. 左腕または右腕の「IK」を押します。現在のFK姿勢に合わせて切り替わり、手首コントローラが選択されます。
4. 手首を移動・回転します。肘の向きを変えるときは「上腕を選択」を押し、上腕の入力コントローラを回転します。通常のMaya操作でキーを設定できます。

手首ターゲットはワールド空間に置かれ、上腕入力は肩の親に追従します。上腕回転はCCDが解く前の姿勢入力で、最終的な腕・肘の回転はソルバーが決めます。腕の長さを超える位置には届きません。

腕が一直線のときに手首だけを真っすぐ内側へ動かすと、曲がり始めない場合があります。先に上腕入力を回転して曲げる方向を与えてください。MMD互換CCDの反復計算では追従残差が生じることがあり、手首位置の厳密な固定を保証する機能ではありません。

## IK中の自動捩り

腕IK中は、上腕入力のロールを腕捩りへ、手首入力のロールを手捩りへ自動で配分します。上腕側は捩り骨へ渡したロールを上腕入力から差し引き、同じ回転を二重に加えません。手捩りは、上腕入力と切替時の肘姿勢を基準に手首の回転から求めます。手首の移動は位置のIK、捩りは回転入力で操作します。

既存の捩りアニメーションを土台として、IKへ切り替えた姿勢からの差分を加えます。補助捩り骨への配分には、モデルに設定された付与率を使用します。対応する固定軸の腕捩り・手捩り骨がないモデルでは、捩り骨を追加しません。

IK中は対応するTwistコントローラを非表示にします。FKへ戻すと再表示され、FKの捩りキーは従来どおり編集できます。「FK」は自動捩りも現在フレームのキーへ移し、「元のFKへ」は有効化前の捩り入力へ戻します。MMDリグへのベイクにも自動捩りを含めます。

ロールは切替姿勢に対する最短角で扱います。180度をまたぐ連続捩りや複数回転の配分は対象外です。

## FKへの切り替えと復元

| ボタン | 結果 |
| --- | --- |
| IK | 現在のFK姿勢に合わせてIKへ切り替えます。すでにIKの場合は手首を選択します。 |
| FK | 現在のIK姿勢を現在フレームのFKキーにして切り替えます。 |
| 元のFKへ | 直前にIKを有効にした時点のFK接続とキーへ戻します。現在のIK姿勢は残しません。 |

Animator Toolset の Body／Finger タブでは、ピッカー下部の「IK / FK」から、選択中のキャラクターの左腕・右腕・視線を切り替えられます。部位名の横に現在のモードが表示されます。コントロールリグを編集状態にしてから使います。

再びIKへ切り替える場合も、既存の手首・上腕入力のキーを削除する必要はありません。現在フレームの姿勢合わせを行い、他フレームのキーは保持します。この切り替え自体はアニメーション可能なIK/FKブレンド属性ではありません。

## 編集結果をMMDへ戻す

「MMDリグへベイク」で、IKの評価結果をMMD骨のキーへ戻します。既存のFKキーと手首・上腕入力のキーを含む範囲を評価します。その後、通常のVMD出力を使用できます。

スクリプトからベイク範囲を指定する場合、腕IKが有効で、元のFKまたはMMD曲線に範囲外のキーがあると停止します。キーを失わないよう、全キーを含む範囲を指定してください。管理画面からのベイクでは範囲を自動で求めます。

「MMDリグの復元」や「コントロールリグの削除」は編集前のMMD接続へ戻す操作です。編集したIKの結果を残す場合は、先にベイクしてください。

腕IKのベイクでは、整数フレームと入力・関連キーの時刻で評価した腕・肘・手首の回転をキーにし、その間をクォータニオンで補間します。ライブIKは時刻ごとに計算し直すため、整数フレームの姿勢が一致しても、その間の回転経路まで一致するとは限りません。差は補助捩り骨だけでなく、通常の上腕・肘の回転や手首位置にも現れます。

肘方向が短時間で大きく変わる区間は、ベイク前後を中間フレームでも比較してください。腕が伸び切っていなくても差が出る場合があります。既存の上腕入力を調整して肘方向の変化を緩やかにすると改善することがありますが、肘の姿勢を変える編集になるため、元の姿勢を保つ自動補正ではありません。

以下の対応範囲では、手首ターゲットと捩り骨を同時に動かしたモーションも、このベイク結果をVMDへ出力できます。VMD出力時には、ベイク済みのシーンを中間フレームでも評価し、その値をVMDの補間で再現できるか検査します。ライブIKからベイクした時点の差や、モデル内蔵の補助IKを含むMMD再生結果との一致を保証するものではありません。

## 現在の対応範囲

腕・肘・手首の3骨を操作する構成を対象とし、モデルのMMDリグと共通の`mmdCcdIk`を使います。RPソルバーや肘ポール、伸び切り専用の三角形計算は使用しません。

腕・肘・手首は、同じ骨に付与とボーンモーフが直列につながっていても操作できます。両ノードの回転XYZがつながり、その出力が骨を駆動する構成が対象です。腕IKは付与とモーフの適用順に合わせてベース回転を補正します。腕捩り・手捩りが独立した付与元の回転やモーフウェイトで動く場合も、手首ターゲットに追従します。

腕IKで解いた腕・肘・手首の回転が中間捩り骨に戻り、その結果が同じ腕IKの入力になる構成は循環するため使用できません。付与・モーフ入力はXYZ回転順に対応し、レイヤー経由の腕入力は対象外です。付与率やモーフの構成・接続を変更する場合は、コントロールリグを削除し、設定を変更してから再セットアップしてください。

複数のモデル内蔵補助IKが付与を介して連動し、腕や捩りの結果が再生履歴に依存する構成は、Control Rigの腕IKのサポート対象外です。切り替えや手首の追従ができても、VMD往復の精度は保証しません。対応範囲はモデル名ではなく接続構成で区別します。

内蔵補助IKを自動でOFFにして結果をベイクする機能や、モデル固有の補正は提供しません。対象外の構成はモデル本来のMMDリグで扱ってください。すべての対象外構成を自動検出して切り替えを禁止する仕組みではありません。

保存された所有情報や接続が手動で変更された場合も、他の入力を切断して操作を続けることはありません。通常の切り替えは管理画面から行ってください。

旧版のRPソルバー・伸び切り専用計算・肘ポール平滑化を含む腕リグは、IKの再有効化時に再構築を案内します。「元のFKへ」やMMDリグの復元・コントロールリグの削除は利用できます。既存の編集を残す場合は、削除前にシーンのコピーを保存してください。

元のFK回転を保存する専用transformを持たない旧腕IKも再構築が必要です。旧構成では、IK中にシーンを保存すると、切り離されたクォータニオン回転キーが再読込時に変わる場合があります。すでに変わったキーは再構築だけでは戻らないため、元のVMDまたは変更前のシーンから作り直してください。
