# MMDスタイル DirectX11 シェーダー設計仕様

## 1. 概要

MikuMikuDance (MMD) の特徴的なトゥーンシェーディング、エッジ（輪郭線）、環境反射をDirectX 11環境で再現するためのシェーダー設計仕様。
このシェーダーは、PMX/PMDモデルファイルに含まれるマテリアル情報を元に、リアルタイムでの描画を行うことを目的とする。

## 2. 基本レンダリング要素

MMDのルックは、以下の要素の組み合わせによって構成される。

- **基本色 (Diffuse Color)**: テクスチャとマテリアルのディフューズカラーの乗算。
- **トゥーンシェーディング (Toon Shading)**: ライトの当たり方に応じた段階的な陰影表現。
- **スペキュラ (Specular)**: 光源からのハイライト。
- **環境光 (Ambient Light)**: シーン全体を均一に照らす光。
- **エッジ / 輪郭線 (Edge / Outline)**: モデルの輪郭を強調する線。
- **スフィアマップ (Sphere Map)**: 疑似的な環境反射。加算または乗算で合成される。
- **セルフシャドウ (Self-Shadow)**: モデル自身が落とす影。

## 3. マテリアルプロパティ

シェーダーは、モデルデータから以下の情報をマテリアル単位で受け取る必要がある。これらは定数バッファ（Constant Buffer）としてシェーダーに渡される。

| プロパティ名 | 型 | 説明 |
| --- | --- | --- |
| ディフューズ色 (Diffuse) | `float4` | 基本色 (RGBA)。アルファ値は透明度。 |
| スペキュラ色 (Specular) | `float3` | ハイライトの色 (RGB)。 |
| スペキュラの強さ (Shininess) | `float` | ハイライトの鋭さ・光沢の強さ。 |
| アンビエント色 (Ambient) | `float3` | 環境光の色 (RGB)。 |
| エッジ色 (EdgeColor) | `float4` | 輪郭線の色 (RGBA)。 |
| エッジサイズ (EdgeSize) | `float` | 輪郭線の太さ。 |
| テクスチャ (MainTexture) | `Texture2D` | モデルに適用する主テクスチャ。 |
| スフィアマップ (SphereTexture) | `Texture2D` | 環境マッピング用のテクスチャ。 |
| スフィアモード (SphereMode) | `int` | `0`:無効, `1`:乗算, `2`:加算 |
| トゥーンテクスチャ (ToonTexture) | `Texture2D` | トゥーンシェーディング用の1Dランプテクスチャ。 |
| 描画フラグ (DrawFlags) | `uint` | 両面描画、地面影、セルフシャドウ等の有効/無効フラグ。 |

## 4. レンダリングパス

MMDのレンダリングは、複数のパスを順に実行することで実現される。

### 4.1. シャドウマップ生成パス (Shadow Map Pass)

- **目的**: セルフシャドウ計算のための深度マップを生成する。
- **処理**:
    1. 光源の視点からシーンをレンダリングする。
    2. 頂点シェーダーで頂点を光源のビュー・プロジェクション空間に変換する。
    3. ピクセルシェーダーは使用せず、深度情報のみを深度バッファ（テクスチャ）に書き込む。

### 4.2. エッジ描画パス (Edge Pass)

- **目的**: モデルの輪郭線を描画する。
- **処理**:
    1. **ラスタライザ設定**: カリングモードを反転させる（`Cull Front`）。これによりポリゴンの裏面のみが描画される。
    2. **頂点シェーダー**:
        - 頂点座標をビュー・プロジェクション空間に変換する。
        - 変換後の頂点を、その頂点の法線方向に「エッジサイズ」分だけ押し出す。
    3. **ピクセルシェーダー**:
        - マテリアルの「エッジ色」をそのまま出力する。

### 4.3. 本体描画パス (Main Pass)

- **目的**: モデル本体の陰影、テクスチャ、反射を計算し描画する。
- **ラスタライザ設定**: 通常のカリングモード（`Cull Back`）。
- **ピクセルシェーダー処理フロー**:
    1. **基本色の計算**:
        - `BaseColor = DiffuseColor * MainTexture.Sample(uv)`
    2. **ライティング計算**:
        - **アンビエント光**: `Ambient = AmbientColor`
        - **ディフューズ光**:
            - `dot_nl = saturate(dot(Normal, LightDir))`
            - この`dot_nl`値をY座標としてトゥーンテクスチャをサンプリング: `ToonFactor = ToonTexture.Sample(float2(0.5, dot_nl))`
            - `Diffuse = LightColor * ToonFactor`
    3. **スペキュラ計算**:
        - ハーフベクトル `H = normalize(LightDir + ViewDir)` を計算。
        - `dot_nh = saturate(dot(Normal, H))`
        - `Specular = SpecularColor * pow(dot_nh, Shininess)`
    4. **セルフシャドウ計算**:
        - ピクセルのワールド座標を光源のビュー・プロジェクション空間に変換し、シャドウマップの深度と比較。
        - 影の中にある場合、`ShadowFactor` を減衰させる（例: 0.3）、そうでなければ 1.0。
    5. **スフィアマップ計算**:
        - 視線ベクトルと法線から反射ベクトルを計算。
        - 反射ベクトルを2D座標に変換し、スフィアマップテクスチャをサンプリング: `SphereColor`
    6. **最終的な色の合成**:
        - `LitColor = (Ambient + Diffuse) * BaseColor + Specular`
        - `LitColor *= ShadowFactor`
        - **スフィアマップ合成**:
            - 乗算モードの場合: `FinalColor.rgb = LitColor.rgb * SphereColor.rgb`
            - 加算モードの場合: `FinalColor.rgb = LitColor.rgb + SphereColor.rgb`
        - `FinalColor.a = BaseColor.a`

## 5. シェーダーへのグローバル入力

以下の情報は、フレームごとに更新されるグローバルな定数バッファとしてシェーダーに渡される。

| プロパティ名 | 型 | 説明 |
| --- | --- | --- |
| World | `float4x4` | ワールド変換行列 |
| View | `float4x4` | ビュー変換行列 |
| Projection | `float4x4` | プロジェクション変換行列 |
| LightView | `float4x4` | 光源のビュー変換行列 |
| LightProjection | `float4x4` | 光源のプロジェクション変換行列 |
| LightDirection | `float3` | 平行光源の方向ベクトル |
| LightColor | `float3` | 光源の色 |
| CameraPosition | `float3` | カメラのワールド座標 |

## 7. Mayaへの導入と使用方法 (MPxShaderOverride)

このシェーダーは、Mayaの `MPxShaderOverride` を介してビューポート2.0に統合される。これにより、ユーザーは単一のカスタムマテリアルを割り当てるだけで、エッジと本体の描画が自動的に行われる。

1.  **プラグインのロード**:
    - Mayaのプラグインマネージャ（`ウィンドウ > 設定/プリファレンス > プラグイン マネージャ`）を開きます。
    - このプロジェクトのプラグイン（例: `maya_mmd_tools.py`）を見つけてロードします。

2.  **カスタムマテリアルの作成**:
    - プラグインをロードすると、ハイパーシェードの作成メニューに新しいマテリアル（例: `MMD Shader`）が追加されます。
    - ハイパーシェード（`ウィンドウ > レンダリング エディタ > ハイパーシェード`）を開き、この `MMD Shader` を作成します。

3.  **マテリアルの割り当て**:
    - シーン内のオブジェクトを選択し、ハイパーシェードで作成した `MMD Shader` を右クリックして `マテリアルを選択項目に割り当て` を選択します。

4.  **パラメータの調整**:
    - `MMD Shader` マテリアルを選択すると、アトリビュートエディタにシェーダーのパラメータ（`DiffuseColor`, `SpecularColor`, `EdgeColor` など）が表示されます。
    - これらの値を調整してルックを決定します。
    - `MainTexture`, `SphereTexture`, `ToonTexture` には、ファイルノードなどを接続します。

5.  **ビューポート設定**:
    - ビューポートのレンダラが `Viewport 2.0` であることを確認してください。
    - ビューポートのライティングを有効にすると、シーンのライトがシェーダーに反映されます。

この方法により、シェーダーの複雑なパス制御はプラグイン側で抽象化され、アーティストやユーザーは直感的にマテリアルを使用できます。
