# ボーンアニメーションをTime Editorで移動する

`MMD > MMD Time Editor` から、読み込んだVMDのボーンアニメーションをMaya標準のクリップへコピーできます。現在は1モデル・1クリップの時間移動と、元のアニメーションへの復元を対象にした実験的な機能です。

## 操作手順

1. PMXモデルを読み込みます。Import画面の「アニメーションレイヤーを使う」をオフにして、VMDを読み込みます。
2. `MMD > MMD Time Editor` を開き、対象モデルを選びます。
3. 「ボーンをクリップ化」を押します。
4. 「Time Editorを開く」を押し、標準Time Editorでクリップを左右へ移動します。クリップ内のボーンアニメーションが移動先の時間で再生されます。
5. 元のVMDの時刻と入力へ戻すには、この管理画面の「クリップ解除」を押します。

クリップ解除は編集結果のベイクではありません。クリップの時間移動を破棄し、作成前のボーン曲線へ戻します。管理画面を閉じてもクリップは残ります。

クリップを使っているモデルへのVMD再読み込み・書き出しは停止します。先に「クリップ解除」で元の入力へ戻してください。解除後に書き出されるのは元のアニメーションで、クリップの時間移動を反映したVMD出力には対応していません。

## 対応範囲

対象はボーンの移動・回転です。モーフ、IKの有効状態、カメラ、ライト、セルフシャドウはクリップに含みません。これらのキーがある場合、ボーンのクリップを動かしても元の時刻に残ります。物理シミュレーションの時間編集も対象外です。

通常Animation Layer、Control Rig編集中、HumanIK、既存の別クリップがあるシーンでは作成を停止します。必要な編集をベイクし、元のMMD入力へ復元してから使用してください。対応しない接続を自動で切断することはありません。

時間を変換するカーブ（非線形の時間補間など）を使う入力も対象外です。Maya標準のSource化でその時間変換が失われるため、元の動きを変えずに扱えない入力はクリップ作成前に停止します。元のキーや補間を自動で線形化することはありません。

クリップのmuteは元のアニメーションへの切り替えではありません。復元には管理画面の「クリップ解除」を使ってください。標準Time Editorでのクリップ削除・複製、Sourceの差し替え、内部接続の手動変更は、この管理機能では扱いません。

モデル・ボーン・namespaceの名前変更には対応していません。クリップ使用中に名前を変えた場合は、変更前の名前へ戻してから解除してください。

trim・速度変更・loop・time warp・ブレンド・Clip Layers・複数モデル／クリップ・編集後のVMD出力は未検証です。これらの全面対応を示す機能ではありません。
