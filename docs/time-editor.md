# VMDをTime Editorのクリップとして読み込む

VMDのボーンモーションを、Maya標準のTime Editorのクリップとしてモデルへ追加できます。クリップはTime Editorで移動・削除でき、同じモデルに何本でも追加できます。実験的な機能です。

## 操作手順

1. PMXモデルを読み込み、MMD Editorで対象モデルを選びます。
2. Import画面のアニメーション読み込みでVMDファイルを指定します。
3. 「Time Editorに読み込む」を押します。fps・モーションスケールなどは通常のVMD読み込みと同じ設定を使います。
4. Maya標準のTime Editor（`Windows > Animation Editors > Time Editor`）でクリップを移動・削除します。

もう一度「Time Editorに読み込む」を押すと、新しいトラックにクリップが追加されます。

## 制限

- クリップに入るのはボーンの移動・回転とIKの有効状態だけです。モーフ・カメラ・ライト・セルフシャドウのキーは読み込みません。
- モーションは毎フレームのキーへベイクされます。元のVMDのキー位置や補間曲線は残りません。
- クリップがあるモデルには、通常のVMD読み込みとVMD書き出しはできません。使うには先にTime Editorでクリップをすべて削除してください。
- クリップをすべて削除すると、モデルは最後に再生していた姿勢のまま止まります。元の姿勢には自動で戻りません。
- アニメーションレイヤー、コンストレイント、HumanIKなどがボーンを動かしているモデルには読み込めません。
- 物理シミュレーションの時間編集は対象外です。
