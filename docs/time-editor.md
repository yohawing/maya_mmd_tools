# VMDをTime Editorのクリップとして読み込む

VMDのモデルモーション（ボーン・モーフ・IKの有効状態）を、Maya標準のTime Editorのクリップとしてモデルへ追加できます。カメラモーションのVMDは、MMDカメラのクリップになります。クリップはTime Editorで移動・削除でき、同じモデルやカメラに何本でも追加できます。実験的な機能です。

## 操作手順

1. PMXモデルを読み込み、MMD Editorで対象モデルを選びます。カメラモーションのVMDだけを読み込むときは、モデルは不要です。
2. Import画面のアニメーション読み込みでVMDファイルを指定します。
3. 「Time Editorに読み込む」を押します。Rig モード、Bake モード、Control Rig のいずれも使えます。fps・モーションスケールも通常のVMD読み込みと同じ設定を使います。
4. Maya標準のTime Editor（`Windows > Animation Editors > Time Editor`）でクリップを移動・削除します。

もう一度「Time Editorに読み込む」を押すと、クリップが追加されます。

- 既存のクリップと同じボーンやモーフを動かすVMD（2本目のダンスなど）は、そのクリップと同じトラックの直後に続けて置かれます。同じトラック上で前のクリップと重ねると、重なった区間がクロスフェードになります。
- 動かす対象が重ならないVMD（体のモーションと表情・リップのモーションなど）は、新しいトラックのフレーム0に置かれ、同時に再生されます。

別々のトラックに置いたクリップが同じボーンを同じ時間に動かすと、Time Editorが両方を同じ重みで混ぜるため、どちらとも違う姿勢になります。トラックを分けたまま重ねないでください。

## 制限

- モデルのクリップに入るのはボーンの移動・回転、モーフ、IKの有効状態です。1つのVMDから1本のクリップになります。モデル用のVMDに含まれるカメラのキーと、ライト・セルフシャドウのキーは読み込みません。
- カメラモーションのVMDは、MMDカメラ（無ければ作成）の位置・回転・画角のクリップになります。通常のカメラ読み込みで生成したキーと補間を使います。
- Rig モードでは移動やモーフのキーは疎なまま残り、VMD の時間ワープを使う回転だけを毎フレームのキーに変換します。Bake モードと Control Rig でも、通常読み込みで生成したカーブを使います。
- モデルやカメラに手付けキーなどのシーンアニメーションがあると、通常読み込み後に残っているキーもクリップに入ります。クリップを削除しても元のシーンキーには戻りません。
- 同じモデルでは、Rig モードと Bake モードのクリップを混ぜないでください。Bake モードの読み込みはモデルの IK・付与を切るため、先に Rig モードで追加したクリップが正しく再生されなくなります。
- クリップがあるモデルには、通常のVMD読み込みとVMD書き出しはできません。クリップがあるMMDカメラも同様に、通常のカメラVMD読み込みとカメラの書き出しはできません。使うには先にTime Editorでクリップをすべて削除してください。
- クリップをすべて削除すると、モデルは最後に再生していた姿勢のまま止まります。元の姿勢には自動で戻りません。
- アニメーションレイヤー、コンストレイント、HumanIKなどがボーンやモーフを動かしているモデルには読み込めません。
- 物理シミュレーションの時間編集は対象外です。
