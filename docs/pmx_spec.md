# PMX仕様 サマリー (v2.1対応)

## 概要

PMXは、MikuMikuDance（MMD）で使用される3Dモデルフォーマットです。PMDの後継として開発され、より高度な機能を提供します。

### 基本情報
- **形式**: バイナリのみ
- **バイト順**: リトルエンディアン
- **テキストエンコード**: UTF-16LE または UTF-8
- **現在の最新バージョン**: 2.1
- **互換性**: バージョンで厳密に管理

## 基本データ型

| 型名 | サイズ | 説明 |
|------|--------|------|
| byte | 1 | 符号なし |
| sbyte | 1 | 符号あり |
| ushort | 2 | 符号なし |
| short | 2 | 符号あり |
| uint | 4 | 符号なし |
| int | 4 | 符号あり |
| float | 4 | 単精度実数 |
| float2 | 8 | Vector2 (X,Y) |
| float3 | 12 | Vector3 (X,Y,Z) |
| float4 | 16 | Vector4 (X,Y,Z,W) |
| TextBuf | 可変 | 4 + バッファ長 |
| bitFlag | 1 | 8フラグ (bit 0:OFF 1:ON) |

### Index参照のサイズ最適化
各データのIndex参照値はデータ総数に応じて1,2,4バイトで最適化されます。
- **頂点**: 符号なし (1:0～255, 2:256～65535, 4:65536～2147483647)
- **その他**: 符号あり (1:0～127, 2:128～32767, 4:32768～2147483647)

## PMXヘッダ

```
4 bytes: "PMX " (ASCII 0x50,0x4d,0x58,0x20)
4 bytes: float version (2.0/2.1)
1 byte:  後続データ列のバイトサイズ (8固定)
8 bytes: 設定情報
  [0] エンコード方式 (0:UTF16, 1:UTF8)
  [1] 追加UV数 (0～4)
  [2] 頂点Indexサイズ (1,2,4)
  [3] テクスチャIndexサイズ (1,2,4)
  [4] 材質Indexサイズ (1,2,4)
  [5] ボーンIndexサイズ (1,2,4)
  [6] モーフIndexサイズ (1,2,4)
  [7] 剛体Indexサイズ (1,2,4)
```

## モデル情報

```
TextBuf: モデル名
TextBuf: モデル名英
TextBuf: コメント
TextBuf: コメント英
```

## 頂点データ

### 基本構造
```
float3: 位置 (x,y,z)
float3: 法線 (x,y,z)
float2: UV (u,v)
float4[n]: 追加UV (x,y,z,w) × 追加UV数
byte: ウェイト変形方式
```

### ウェイト変形方式
- **BDEF1 (0)**: 単一ボーン
- **BDEF2 (1)**: 2ボーン + ウェイト値
- **BDEF4 (2)**: 4ボーン + 各ウェイト値
- **SDEF (3)**: BDEF2 + SDEF用パラメータ
- **QDEF (4)**: デュアルクォータニオン方式 (v2.1)

```
float: エッジ倍率
```

## 面データ

```
頂点Index × 3 (三角形面)
```
- 材質毎の面数は材質内で管理
- v2.1ではPoint描画(A-A-A)、Line描画(A-B-A)もサポート

## テクスチャ

```
TextBuf: テクスチャパス
```
- 材質から参照されるテーブル
- 共有Toon (toon01.bmp～toon10.bmp) は含まれない

## 材質データ

```
TextBuf: 材質名
TextBuf: 材質名英
float4: Diffuse (R,G,B,A)
float3: Specular (R,G,B)
float: Specular係数
float3: Ambient (R,G,B)
bitFlag: 描画フラグ
  0x01:両面描画, 0x02:地面影, 0x04:セルフシャドウマップ描画
  0x08:セルフシャドウ描画, 0x10:エッジ描画
  0x20:頂点カラー(v2.1), 0x40:Point描画(v2.1), 0x80:Line描画(v2.1)
float4: エッジ色 (R,G,B,A)
float: エッジサイズ (Point描画時はPointサイズ)
テクスチャIndex: 通常テクスチャ
テクスチャIndex: スフィアテクスチャ
byte: スフィアモード (0:無効, 1:乗算sph, 2:加算spa, 3:サブテクスチャ)
byte: 共有Toonフラグ
ToonテクスチャIndex または 共有Toon番号
TextBuf: メモ
int: 材質対応面数
```

## ボーンデータ

```
TextBuf: ボーン名
TextBuf: ボーン名英
float3: 位置
ボーンIndex: 親ボーン
int: 変形階層
ushort: ボーンフラグ
```

### ボーンフラグ
- **0x0001**: 接続先表示方法 (0:座標オフセット, 1:ボーン指定)
- **0x0002**: 回転可能
- **0x0004**: 移動可能
- **0x0008**: 表示
- **0x0010**: 操作可
- **0x0020**: IK
- **0x0080**: ローカル付与
- **0x0100**: 回転付与
- **0x0200**: 移動付与
- **0x0400**: 軸固定
- **0x0800**: ローカル軸
- **0x1000**: 物理後変形
- **0x2000**: 外部親変形

### フラグ依存データ
各フラグに応じて追加データが格納されます：
- 接続先、付与、軸固定、ローカル軸、外部親変形、IK等

## モーフデータ

```
TextBuf: モーフ名
TextBuf: モーフ名英
byte: 操作パネル (1:眉, 2:目, 3:口, 4:その他, 0:システム予約)
byte: モーフ種類
int: オフセット数
```

### モーフ種類
- **0**: グループ
- **1**: 頂点
- **2**: ボーン
- **3**: UV
- **4-7**: 追加UV1-4
- **8**: 材質
- **9**: フリップ (v2.1)
- **10**: インパルス (v2.1)

### 主要モーフオフセット
- **頂点モーフ**: 頂点Index + 座標オフセット
- **ボーンモーフ**: ボーンIndex + 移動量 + 回転量(クォータニオン)
- **材質モーフ**: 材質Index + 演算形式 + 各種パラメータ
- **グループモーフ**: モーフIndex + モーフ率

## 表示枠データ

```
TextBuf: 枠名
TextBuf: 枠名英
byte: 特殊枠フラグ (0:通常枠, 1:特殊枠)
int: 枠内要素数
要素データ × 要素数
  byte: 要素対象 (0:ボーン, 1:モーフ)
  対応Index
```

## 剛体データ

```
TextBuf: 剛体名
TextBuf: 剛体名英
ボーンIndex: 関連ボーン (-1:関連なし)
byte: グループ
ushort: 非衝突グループフラグ
byte: 形状 (0:球, 1:箱, 2:カプセル)
float3: サイズ
float3: 位置
float3: 回転 (ラジアン)
float: 質量
float: 移動減衰
float: 回転減衰
float: 反発力
float: 摩擦力
byte: 物理演算タイプ (0:ボーン追従, 1:物理演算, 2:物理+位置合わせ)
```

## Jointデータ

```
TextBuf: Joint名
TextBuf: Joint名英
```

- **0**: スプリング6DOF

- **2**: P2P
- **3**: ConeTwist
- **4**: Slider

```

float3: 回転制限下限/上限

```

## v2.1拡張機能

### 新ウェイト変形方式
- **QDEF**: デュアルクォータニオン方式のスキニング

### 新材質機能
- **頂点カラー**: 追加UV1を頂点色として利用
- **Point描画**: PointListプリミティブ
- **Line描画**: LineListプリミティブ

### 新モーフ種類
- **フリップモーフ**: 複数モーフから一つを選択
- **インパルスモーフ**: 剛体への力/トルク適用

### SoftBodyデータ
```
TextBuf: SoftBody名
TextBuf: SoftBody名英
byte: 形状 (0:TriMesh, 1:Rope)
材質Index: 関連材質
byte: グループ
ushort: 非衝突グループフラグ
bitFlag: フラグ (B-Link作成, クラスタ作成, リンク交雑)
各種パラメータ (Config, Cluster, Iteration, Material)
アンカー剛体データ
Pin頂点データ
```

## 変形順序とアルゴリズム

### ボーン変形順序
1. 物理前/後で分類
2. 変形階層順
3. Index順

### 付与システム
- 付与親の変形量を自身に追加
- 多重付与対応
- ローカル付与とグローバル付与

### IKシステム
- CCDIKアルゴリズム
- 角度制限対応
- リンク構造

## 物理演算

### 変形順序
```
ボーン変形 (物理前) → 物理演算 → ボーン変形 (物理後)
```

### SoftBody (v2.1)
- Bulletライブラリベース
- TriMesh / Ropeサポート
- アンカー剛体、Pin頂点による制御

## 実装時の注意点

1. **バージョン管理**: 非対応バージョンは処理中断
2. **エンディアン**: リトルエンディアン必須
3. **Index最適化**: データ数に応じたサイズ調整
4. **変形順序**: 正確な順序での変形処理
5. **多重付与**: 付与親の依存関係に注意
6. **物理演算**: Bullet 2.75基準での実装
7. **テクスチャパス**: 相対パス対応
8. **エラーハンドリング**: 不正データでの安全な処理中断

## PMDとの主な違い

- より柔軟なインデックスサイズ
- 追加UV対応
- 高度なモーフシステム
- 物理演算の拡張
- SoftBody対応 (v2.1)
- 複数Joint種類 (v2.1)
