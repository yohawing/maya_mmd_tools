# プロジェクトマネージメントシート (アジャイル開発)

## プロジェクト概要

*   **プロジェクト名:** Maya MMD Tools
*   **目的:** Autodesk Maya に MMD (MikuMikuDance) のモデルおよびモーションファイルをインポートする機能を提供し、MMD コンテンツの Maya での利用を可能にする。
*   **ビジョン:** Maya ユーザーが MMD アセットをシームレスに活用し、より豊かな 3D コンテンツ制作を行えるようにする。

## チーム構成

## バックログ管理

*   **プロダクトバックログ:** プロジェクトの全ての要件（機能、改善、バグ修正など）を優先順位付けしてリスト化。
*   **スプリントバックログ:** 各スプリントで開発チームがコミットするプロダクトバックログアイテムのサブセット。
*   **ユーザーストーリーの定義:**
    *   `As a [ユーザータイプ], I want to [機能], so that [価値].` の形式で記述。
    *   例: `As a Maya user, I want to import PMX models, so that I can use MMD characters in my Maya scenes.`

## 品質管理

*   **完了の定義 (Definition of Done - DoD):** 各バックログアイテムが「完了」と見なされるための基準。
    *   コードがレビューされた。
    *   ユニットテストがパスした。
    *   統合テストがパスした。
    *   ドキュメントが更新された。
    *   UI テストが完了した。
*   **テスト戦略:** `doc/testing.md` を参照。

## 課題と障害

### 現在の課題
*   **Maya環境依存:** 統合テストの実行にMaya環境が必要なため、CI/CDパイプラインの構築が困難
*   **UI/UX:** ユーザーフレンドリーなインターフェースの設計と実装が必要
*   **物理演算システムの最適化:** PMXインポート時に過剰な数のhairSystemとnRigidが作成される問題（78個のhairSystem、85個のnRigid）→ **MMD-18**で対応予定
*   **モーフターゲットの管理:** 各モーフごとに完全なメッシュ複製が作成され、ShapeOrigノードが重複する問題（100以上のモーフで深刻なメモリ使用量増加）→ **MMD-19**で対応予定
