# プロジェクトマネージメントシート (アジャイル開発)

## プロジェクト概要

*   **プロジェクト名:** Maya MMD Tools
*   **目的:** Autodesk Maya に MMD (MikuMikuDance) のモデルおよびモーションファイルをインポートする機能を提供し、MMD コンテンツの Maya での利用を可能にする。
*   **ビジョン:** Maya ユーザーが MMD アセットをシームレスに活用し、より豊かな 3D コンテンツ制作を行えるようにする。

## 課題と障害

### 現在の課題
*   **Maya環境依存:** 統合テストの実行にMaya環境が必要なため、CI/CDパイプラインの構築が困難
*   **テストデータ管理:** 大きなMMDファイルをリポジトリに含めることによるファイルサイズの問題
*   **パフォーマンス:** 大きなMMDファイルの処理時間の最適化が必要
*   **UI/UX:** ユーザーフレンドリーなインターフェースの設計と実装が必要

### 解決済み課題
*   **Unicode文字エンコーディング:** 日本語文字列の処理問題を`unicode_converter.py`で解決
*   **データ構造の複雑さ:** モジュール化により各データ構造を独立したクラスとして実装
*   **設定管理:** JSON設定ファイルとMayaのoptionVarを組み合わせた永続化機能を実装

### 今後の対応予定
*   **モックテスト:** Maya環境に依存しないテストケースの追加
*   **パフォーマンス最適化:** Maya Python API 2.0の活用による高速化
*   **エラーハンドリング:** より詳細なエラーメッセージとログ出力の実装
