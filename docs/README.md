## ⚠️ アルファ版について

現在、Maya MMD Toolsはアルファ版です。以下の点にご注意ください：

- 一部の機能が不安定な場合があります
- すべてのMMDファイルに対応していない可能性があります
- 重要なプロジェクトで使用する前に必ずバックアップを取ってください
