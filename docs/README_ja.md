# Maya MMD Tools ユーザードキュメント

[English](../README.md)


Maya MMD Toolsは、Autodesk MayaでMikuMikuDance (MMD) のPMD/PMXモデルとVMDモーションを読み込み、編集し、PMX/VMDとして書き出すためのツールです。
書き出しは、検証済みの対応範囲に限定して公開しています。

> [!WARNING]
> ※本ツールは現在アルファ版で、UIや操作手順が変更される可能性があります。そのため、各機能の詳細な操作ガイドはまだ用意していません。詳細は下記の機能表を参照してください。

## 機能サポート一覧

凡例: ✅ 対応 · ℹ️ 一部対応／制限あり · 🧪 試験的 · ⛔ 未対応

### モデル（PMX,PMD）

| 機能 | 状態 | 備考 |
|---|---|---|
| メッシュ | ℹ️ | SDEF/QDEFはリニアスキンウェイトとして読み込み、BDEF4として書き出します。固有の変形方式は保持しません。追加UVはメタデータとして保持します。 |
| マテリアル・テクスチャ | ℹ️ | DX11・OpenGLシェーダーによるMMDトゥーンシェーダーを実装しています。共有Toonと個別Toonを含む対応フィールドを編集・書き出しできますが、Viewport 2.0の制約により表示の完全一致は保証しません。 |
| Maya向け名前解決 | ✅ | 辞書・またはハッシュにより安全な名前に変換します。またパスのテクスチャを安全なパスに自動解決します。 |
| エッジ／輪郭フラグ | ℹ️ | オプションで有効にできますが、Viewport 2.0の制約があります。 |
| ボーン・スケルトン・リグ（IK・付与・ローカル軸） | ℹ️ | PMX 2.0の基本的なIK・付与・軸・物理後変形などを保持します。複雑なリグには既知の問題があります。 |
| 表示枠 | ℹ️ | 表示枠の名前・特殊枠・ボーン／モーフ項目を編集できます。 |
| モーフ（頂点・ボーン・マテリアル・グループ・UV） | ℹ️ | 頂点・ボーン・マテリアル・グループは対応済み。PMX 2.0のUV／追加UVモーフ（type 3–7）はエクスポートと再インポートでメタデータを保持しますが、MayaのUV setは変形しません。Flip、Impulseモーフは未対応です。 |
| 物理（剛体・ジョイント） | ℹ️ | PMX/PMDの物理データは既定で読み込みます。一部の編集操作は未対応です。 |
| ソフトボディ（PMX 2.1） | ⛔ | 未対応 |
| エクスポート | ℹ️ | 検証済みフィールドをPMX 2.0として書き出します。未対応データは検証で停止し、既存ファイルを上書きしません。PMDはインポート専用です。 |

### アニメーション（VMD）

| 機能 | 状態 | 備考 |
|---|---|---|
| ボーンアニメーション | ℹ️ | 基本的なMMDリグに対応していますが、複雑なギミックには未対応です。ベイク書き出しには [mmd-anim](https://github.com/yohawing/mmd-anim) を使用します。 |
| VPD | ✅ | ドラッグ＆ドロップインポートのみの対応 |
| モーフアニメーション | ℹ️ | 頂点・ボーン・マテリアルに対応。UVモーフのmetadataは開発用の再出力用に保持しますが、MayaのUV setランタイム評価は未検証です。Flip、Impulseモーフは未対応です。 |
| カメラアニメーション | ✅ | `mmd_camera` を作成・キー設定し、ライティングは`mmd_light` コントローラを駆動します。カメラ／ライト／セルフシャドウのVMD書き出しは非対応です。 |
| IK オン／オフフレーム | ℹ️ | インポート・ベイクに対応。ランタイムベイクでは最終姿勢に反映され、リグモードでは `mmdCcdIk.enabled` にキーを設定します。 |
| 物理 | ℹ️ | Bulletによる物理演算（リアルタイム／ベイク）に対応しています。読み込み時はOFFで物理タブでONにできます。まだ精度が低いです。 |
| HumanIK・リターゲット | 🧪 | MMDモデル同士のリターゲットに試験対応。`MMD > HumanIK (Experimental)` からお試しください。 |
| コントロールリグ | 🧪 | 準標準ボーン構成に基づいたコントロールリグをオプションで生成できます。 |
| エクスポート | ℹ️ | 現在のキャラクターと指定タイムラインを常にベイクして書き出します。元VMDのキーや補間との同一性は保証しません。カメラ／ライト／セルフシャドウは書き出しません。 |

## 既知の制限

- **α版のため、詳細なドキュメントは未作成です** ドキュメントの管理コストより、開発速度を優先するためです。
- **様々な機能が未実装な機能のまま公開されています。** α版の試験的公開なので、ご容赦ください。フィードバックお待ちしております。
- **QDEF、SDEFはBDEF4へ劣化変換します** 固有の変形方式を保持しないため、一部のモデル＋モーションでメッシュが痩せてしまう場合があります。
- **エクスポートは検証済みの限定範囲に対応します。** PMXの変形はBDEF4へ統一し、SDEF/QDEF固有のデータは保持しません。追加UVとUV／追加UVモーフのメタデータは書き出し・再読み込みまで保持しますが、MayaのUV setは変形しません。Flip、Impulse、ソフトボディは書き出しません。PMDはインポート専用です。VMDは現在のキャラクターを固定のベイク書き出しで評価し、カメラ／ライト／セルフシャドウは書き出しません。
- **HumanIKが試験的な機能として公開されています** 必要最低限の機能として公開されています。`MMD > HumanIK (Experimental)`からお試しください。
- **脚の回転や、ボーンモーフと競合する骨はコントロールリグ下でしか動作しません。** 　ボーンモーフと骨の接続が競合すると骨が動かせなくなってしまう場合があります。

## システム要件

### 必須要件

- **Maya**: 2024以降
- **OS**: Windows 11 / macOS 15.6
- **Python**: 3.10以降（Maya 2024以降に同梱）

## インストール

### ファイルのダウンロード

1. [GitHubリリースページ](https://github.com/yohawing/maya_mmd_tools/releases)から最新版をダウンロードします。
2. ZIPファイルを一時フォルダへ解凍します。

### ドラッグ＆ドロップでインストール

1. Mayaを起動します。
2. 解凍したフォルダ内の `drag_drop_install.py` をMayaのビューポートへドラッグ＆ドロップします。
3. インストール確認ダイアログを確認します。
4. Mayaを再起動します。

インストーラはMaya MMD Tools本体のファイル一式をMayaのユーザー `modules` フォルダへコピーし、その隣に `maya_mmd_tools.mod` を作成します。

### プラグインの有効化

1. Mayaを起動します。既に起動している場合は再起動します。
2. `Window > Settings/Preferences > Plug-in Manager` を開きます。
3. `mmd_tools_plugin.py` を探します。
4. `Loaded` にチェックを入れます。
5. 自動読み込みしたい場合は `Auto load` にもチェックを入れます。
6. MMDに寄せたシェーダーにしたい場合は、`dx11Shader`にもチェックを入れてください。`MMDシェーダーを作成` は既定でONです。

## インストールの確認

### メニューで確認

Mayaのメニューバーに `MMD > MMD Editor` が追加されていることを確認します。

## クイックスタート

### MMD Editorを開く

1. `MMD > MMD Editor` を選択します。
2. MMD Editorウィンドウが開きます。
3. 各タブで設定を確認・調整できます。

UI項目はPMX Editorの構成を参考にしています。未対応の項目やデータは検証時に理由を表示して書き出しを停止します。

### モデルをインポートする

1. ImportタブでインポートするPMXまたはPMDファイルを選択します。
2. `Import Model` をクリックします。

※テクスチャがマルチバイト文字によって読み込めない場合は、テクスチャを自動修復をONにしてください。自動で読み込める名前のテクスチャに自動でコピーされ使用されます。

### アニメーションをインポートする

1. インポートタブでVMDファイルを選択します。
1. `Import Animation` をクリックします。
1. シーン内の対応するモデルにアニメーションが適用されます。

### モデルを作成・編集する

1. インポートタブの `モデルを作成` から同梱テンプレートを選択します。
2. マテリアル、ボーン、モーフなどのタブで現在のモデルを編集します。

### モデル／アニメーションを書き出す

1. 書き出すモデルを現在のモデルとして選択します。
2. エクスポートタブで `モデル` または `アニメーション` を選択します。
3. 検証結果を確認してからPMXまたはVMDを書き出します。アニメーションは現在のタイムラインをベイクして書き出します。

### HumanIK（試験的）の使い方

1. メニューバーの `MMD > HumanIK（Experimental）` から専用Windowが開きます。
2. MMDキャラクターのRootを選択し、`選択モデルをセットアップ`を押すと、キャラクター定義が作成されます。
3. ２体キャラクターを読み込みセットアップ後にSOURCEにモーションの入ったキャラクターを設定することにより、モーションリターゲットが可能になります。
4. リターゲットしたモーションから、コントロールリグにベイクしたりできます。
5. `MMDリグを復元`はControlリグから安全にMMDリグに戻ることが出来ます。

※ MayaのHumanIKの機能を使うと、一部の動作でMMDのリグが壊れてしまうことがあります。

## ビューポートの設定

MMDのトゥーン表現を再現するシェーダーは、MMDシェーダーの作成オプションと、レンダリング環境に応じたシェーダープラグインを有効にすることで確認出来ます。Windows 環境では `dx11Shader` プラグイン、MacOS 環境では `glslShader`（GLSLShader）プラグインを使用します。
また、インポート時に以下の設定が自動で適用されます。

- **レンダリング空間** → `ACEScg`　→ `scene-linear Rec.709-sRGB`。
- **ビュー変換（View Transform）** `ACES 1.0 SDR-video (sRGB)` → `Un-tone-mapped (sRGB)`

いずれもMMDらしい色調（sRGBガンマ空間入出力）を再現する目的での適用になります。
