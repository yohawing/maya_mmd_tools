# Maya MMD Tools ユーザードキュメント

[English](../README.md)


MayaでMikuMikuDance (MMD) のPMD/PMX/VMDを読み込み、編集、書き出しをするためのツールです。


![feature](./assets/feature.png)

> クレジット — モデル: [げのげ式ミク](https://bowlroll.net/file/320915)

> [!WARNING]
> ※本ツールは現在アルファ版で、UIや操作手順が変更される可能性があります。そのため、各機能の詳細な操作ガイドはまだ用意していません。詳細は下記の機能表を参照してください。

## 機能サポート一覧

凡例: ✅ 対応 · ℹ️ 一部対応／制限あり · 🧪 試験的

### モデル（PMX,PMD）

| 機能 | 状態 | 備考 |
|---|---|---|
| メッシュ | ℹ️ | SDEF/QDEFの読み込みは対応していません、BDEF4相当として読み込まれます。追加UVはメタデータとして保持します。 |
| マテリアル・テクスチャ | ℹ️ | RenderOverrideによるMMDシェーダーを実装しています。（DirectX描画専用）ビューポートのレンダラ > MMD Renderで切り替えることが出来ます。|
| Maya向け名前解決 | ✅ | 辞書・またはハッシュにより安全な名前（英語またはハッシュ）に変換します。また英語でない画像パスを安全なパスに自動解決します。 |
| ボーン・スケルトン・リグ（IK・付与・ローカル軸） | ℹ️ | PMX 2.0の基本的なIK・付与・軸・物理後変形などに対応しています。複雑なリグには既知の問題があります。 |
| 表示枠 | ✅ | 表示枠の名前・特殊枠・ボーン／モーフ項目を編集できます。 |
| モーフ（頂点・ボーン・マテリアル・グループ・UV） | ℹ️ | 頂点・ボーン・マテリアル・グループは対応済み。PMX 2.0のUV／追加UVモーフ（type 3–7）はエクスポートと再インポートでメタデータを保持しますが、MayaのUV setには反映されません。 |
| 物理（剛体・ジョイント） | ℹ️ | パフォーマンスや品質に既知の問題があります。一部の編集操作は未対応です。 |
| エクスポート | 🧪 | 書き出しは試験的な対応です。幅広いモデルでの動作確認は未完了です。 |

### アニメーション（VMD）

| 機能 | 状態 | 備考 |
|---|---|---|
| ボーンアニメーション | ℹ️ | 基本的なMMDリグに対応していますが、複雑なギミックには未対応です。ベイク書き出しには [mmd-anim](https://github.com/yohawing/mmd-anim) を使用します。 |
| VPD | ✅ | ドラッグ＆ドロップでインポートできます。|
| モーフアニメーション | ℹ️ | UVモーフは未検証です。材質モーフは標準材質のプレビューとMMD Renderに反映されます。標準プレビューでは色・不透明度を近似表示します。 |
| カメラアニメーション | ✅ | `mmd_camera` を作成・キー設定し、ライティングは`mmd_light` コントローラを駆動します。 |
| IK オン／オフフレーム | ℹ️ | インポート・ベイクに対応。ランタイムベイクでは最終姿勢に反映され、リグモードでは `mmdCcdIk.enabled` にキーを設定します。 |
| 物理 | ℹ️ | Bulletによる物理演算（リアルタイム／ベイク）に対応しています。読み込み時はOFFで物理タブでONにできます。まだ精度が低いです。 |
| HumanIK・リターゲット | 🧪 | MMDモデル同士のリターゲットに試験対応。`MMD > HumanIK (Experimental)` からお試しください。 |
| コントロールリグ | 🧪 | 準標準ボーン構成に基づいたコントロールリグをオプションで生成できます。復元やベイクに既知の問題があります。 |
| エクスポート | 🧪 | VMD（キャラ・カメラ・ライト）対応。VPD対応。現状ベイク書き出しのみです。セルフシャドウは未対応です。 |


## 既知の制限

- **α版のため、詳細なドキュメントは未作成です** ドキュメントの管理コストより、開発速度を優先するためです。
- **QDEF、SDEFはBDEF4へ劣化変換します** 固有の変形方式を保持しないため、一部のモデル＋モーションでメッシュが痩せてしまう場合があります。
- **脚の回転や、ボーンモーフと競合する骨はコントロールリグ下でしか動作しません。** 　ボーンモーフと骨の接続が競合すると骨が動かせなくなってしまう場合があります。

## システム要件

### 必須要件

- **Maya**: 2024以降
- **OS**: Windows 11 / macOS 15.6
- **Python**: 3.10以降（Maya 2024以降に同梱）

## インストール

### ファイルのダウンロード

1. [GitHubリリースページ](https://github.com/yohawing/maya_mmd_tools/releases)から最新版をダウンロードします。
2. ZIPファイルを一時フォルダへ解凍します。

### ドラッグ＆ドロップでインストール

1. Mayaを起動します。
2. 解凍したフォルダ内の `drag_drop_install.py` をMayaのビューポートへドラッグ＆ドロップします。
3. インストール確認ダイアログを確認します。
4. Mayaを再起動します。

※インストーラはMaya MMD Tools本体のファイル一式をMayaのユーザー `modules` フォルダへコピーし、その隣に `maya_mmd_tools.mod` を作成します。

### プラグインの有効化

1. Mayaを起動します。既に起動している場合は再起動します。
2. `ウィンドウ > 設定・プリファレンス > プラグインマネージャー` を開きます。
3. `mmd_tools_plugin.py` を探します。
4. `ロード` にチェックを入れます。自動読み込みしたい場合は `自動ロード` にもチェックを入れます。
5. Mayaのメニューバーに `MMD > MMD Editor` が追加されていることを確認します。

## クイックスタート

### MMD Editorを開く

1. `MMD > MMD Editor` を選択します。
2. MMD Editorウィンドウが開きます。
3. 各タブで設定を確認・調整できます。

UI項目はPMX Editorの構成を参考にしています。

### モデルをインポートする

1. ImportタブでインポートするPMXまたはPMDファイルを選択します。
2. `モデルをインポート` をクリックします。

### アニメーションをインポートする

1. インポートタブでVMDファイルを選択します。
1. `アニメーションをインポート` をクリックします。
1. シーン内の対応するモデルにアニメーションが適用されます。

### モデルを作成・編集する

1. インポートタブの `モデルを作成` から同梱テンプレートを選択します。
2. マテリアル、ボーン、モーフなどのタブで現在のモデルを編集します。

### モデル／アニメーションを書き出す

1. 書き出すモデルを現在のモデルとして選択します。
2. エクスポートタブで `モデル` または `アニメーション` を選択します。
3. 検証結果を確認してからPMXまたはVMDを書き出します。
