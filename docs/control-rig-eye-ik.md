# 視線ターゲットで目を動かす

コントロールリグ管理の「視線 IK / FK」から、両目の共通の向きを操作できます。左右眼の個別の補正や既存の付与は保持します。左右眼を一点へ収束させる寄り目の操作ではありません。

## 操作手順

1. アニメーターツールセットから「コントロールリグを管理」を開き、対象キャラクターを選びます。
2. 「セットアップ」、または「コントロールリグへベイク」で編集状態にします。
3. 「視線ターゲット」を押します。現在の姿勢に合わせてターゲットが作成・選択されます。
4. ターゲットを移動して視線を変え、移動チャンネルへキーを設定します。目の傾き（ロール）を変える場合はターゲットを回転します。

ターゲットは両目骨の親の空間に置かれ、頭の移動・回転に追従します。視線IKが有効な間に「視線ターゲット」を押すと、既存のターゲットを選択します。

## FKへの切り替えとベイク

「FK」は現在の姿勢を現在フレームのFKキーへ残して切り替えます。「元のFKへ」は、視線IKを有効にする前のFK接続とキーへ戻します。切り替え自体は、アニメーション可能なIK/FKブレンド属性ではありません。

ターゲットで編集した動きをMMD骨へ戻すには「MMDリグへベイク」を使います。その後、通常のVMD出力を使用できます。「MMDリグの復元」や「コントロールリグの削除」で元の入力へ戻す前に、残したい編集結果をベイクしてください。

スクリプトでベイク範囲を指定する場合、元のFKまたはMMD曲線に範囲外のキーがあると停止します。全キーを含む範囲を指定してください。管理画面では範囲を自動で求めます。

## 現在の対応範囲

両目骨の通常入力と、両目から左右眼への既存付与を使う構成が対象です。特殊な入力や所有情報が変更された接続では、理由を表示して停止します。ターゲットを目の位置に重ねたり、視線をターゲットの上方向と完全に平行にすると、Mayaの標準aim計算で向きが定まらなくなるため避けてください。

「両目コントローラなし」と表示される場合は、両目骨の有無と入力構成を確認してください。この機能の追加前に構築したリグにも、両目コントローラは自動追加されません。対応するモデルで作り直す場合は、必要な編集をMMDリグへベイクしてからコントロールリグを削除し、再度セットアップします。

元のFK回転を保存する専用transformを持たない旧視線IKは、再有効化する前に再構築が必要です。旧構成ではIK中の保存・再読込で元のクォータニオン回転キーが変わる場合があります。有効中のターゲット選択、「元のFKへ」、MMDリグの復元は利用できますが、すでに変わったキーは元のVMDまたは変更前のシーンから戻してください。
