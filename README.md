# Maya MMD Tools

このプロジェクトは、MMDのデータフォーマットをAutodesk Mayaで扱うためのPythonプラグインです。
以下の機能を提供します
- MikuMikuDance (MMD) のファイルフォーマット PMD, PMX, VMD, VPD をMayaシーンにインポート
- PMX, VMD, VPDファイルのエクスポート
